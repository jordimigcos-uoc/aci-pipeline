# Domini URL ACI ↕ Perfil Informe
Com funciona?
GitHub Pages serveix contingut estàtic; per tant, el pipeline Python s'executa dins d'una GitHub Action i exporta els resultats (HTML, JSON, CSV) a aquesta pàgina. Per llençar una nova anàlisi manualment:
  1. Ves a Actions → Publica resultats a GitHub Pages al teu repositori.
  2. Fes clic a Run workflow, tria el perfil i el fitxer d'URLs.
  3. En 2–5 minuts, la pàgina s'actualitzarà amb els nous resultats.
