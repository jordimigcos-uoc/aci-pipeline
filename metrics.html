Fórmula ACI

L'Índex d'Accessibilitat i Comprensió (ACI) és una puntuació composada que agrega 16 mètriques d'accessibilitat web en una escala de 0 a 100.

ACI = ( Σ ni · wi ) / ( Σ wi ) × 100 ∈ [0, 100]

On ni és el valor normalitzat de la mètrica i (rang [0, 1]) i wi és el seu pes dins del perfil de puntuació seleccionat.

Interpretació: ≥ 70 → Excel·lent · 50–69 → Acceptable · < 50 → Insuficient

Principis WCAG 2.1 (agregats)

Les 16 mètriques s'agrupen en els 4 principis fonamentals de WCAG 2.1:

Perceptible (1.x)
Contrast de color, cobertura alt text, jerarquia capçaleres
Operable (2.x)
Focus visible, mida objectiu, navegació per teclat
Comprensible (3.x)
Llegibilitat Flesch, complexitat textual, jerarquia capçaleres
Robust (4.x)
Rols ARIA vàlids, noms accessibles, violacions crítiques/altes

Perfils de puntuació

Cada perfil assigna pesos diferents a les 16 mètriques per reflectir prioritats distintes d'accessibilitat:

Perfil Enfocament Mètriques prioritàries Σ Pesos
WCAG Strict Compliment estricte dels criteris WCAG 2.1 AA Contrast, focus, ARIA, violacions d'auditoria 54
Readability First Prioritat a la llegibilitat i comprensió del contingut Flesch, complexitat, capçaleres, alt text 35
Visual First Prioritat a la qualitat visual i contrast Contrast, mida objectiu, rendiment LCP, landmarks 37

Les 16 mètriques d'accessibilitat

El pipeline ACI analitza 16 mètriques agrupades en 4 sub-puntuacions: WCAG (8 mètriques), Text (3), Elements (4) i Rendiment (1).

# Mètrica Grup Ref. WCAG Descripció Com es mesura
1 Contrast de color WCAG 1.4.3 AA Proporció de contrast entre text i fons. WCAG exigeix mínim 4.5:1 (text normal) o 3:1 (text gran). Playwright + axe-core: ratio de contrast de tots els elements de text
2 Visibilitat del focus WCAG 2.4.7 AA Proporció d'elements interactius amb indicador de focus visible al navegar per teclat. Playwright: detecció d'outline CSS i :focus-visible
3 Mida objectiu tàctil WCAG 2.5.8 AA Proporció d'elements interactius (botons, enllaços) amb mida mínima de 24×24 px. Playwright: getBoundingClientRect() per a tots els elements clicables
4 Navegació per teclat WCAG 2.1.1 A Cobertura de funcionalitat accessible per teclat sense trampes de focus. Playwright: simulació de navegació Tab + detecció de trampes de focus
5 Rols ARIA vàlids WCAG 4.1.2 AA Proporció d'atributs ARIA (role, aria-*) amb valors vàlids i coherents amb el context. axe-core: regles aria-allowed-attr, aria-required-attr, aria-valid-attr
6 Noms accessibles WCAG 4.1.2 AA Cobertura d'elements interactius (botons, formularis, imatges) amb nom accessible. axe-core: regles label, button-name, image-alt, link-name
7 Violacions crítiques WCAG Múltiples Proporció d'absència de violacions crítiques axe-core (impacte=critical). Valor alt = menys violacions. axe-core: violations filtrades per impact=critical
8 Violacions altes WCAG Múltiples Proporció d'absència de violacions altes axe-core (impacte=serious). axe-core: violations filtrades per impact=serious
9 Llegibilitat Flesch Text 3.1.5 AAA Índex de llegibilitat Flesch-Kincaid adaptat al català/castellà. Valors alts indiquen text més llegible. M4-Text: textstat amb el text principal de la pàgina
10 Complexitat textual Text 3.1 AA Indicador invers de complexitat: paraules llargues, frases complexes, vocabulari especialitzat. M4-Text: anàlisi morfosintàctica del cos del text
11 Jerarquia de capçaleres Text 1.3.1 A Coherència de l'estructura h1–h6: absència de salts de nivell i presència d'un únic h1. Playwright: extracció i validació de l'ordre de capçaleres
12 Alt text d'imatges Elements 1.1.1 A Proporció d'imatges no decoratives amb atribut alt no buit i descriptiu. Playwright + axe-core: imatges sense alt o amb alt buit
13 Landmarks de navegació Elements 1.3.6 AAA Cobertura de regions HTML5/ARIA: main, nav, header, footer, aside, section amb etiqueta. Playwright: detecció d'elements landmark i roles ARIA equivalents
14 Violacions moderades Elements Múltiples Proporció d'absència de violacions moderades axe-core (impacte=moderate). axe-core: violations filtrades per impact=moderate
15 Violacions baixes Elements Múltiples Proporció d'absència de violacions menors axe-core (impacte=minor). axe-core: violations filtrades per impact=minor
16 LCP (Core Web Vitals) Rendiment EN 301 549 Largest Contentful Paint normalitzat. LCP ≤ 2.5s → 100; LCP ≥ 4s → 0. Afecta usabilitat i accessibilitat cognitiva. Playwright: PerformanceObserver LCP entry al carregament

Mòduls del pipeline ACI

M1
Captura
Playwright headless: carrega la pàgina, captura DOM + captures de pantalla
M2
Auditoria
axe-core: detecta violacions WCAG/ARIA classificades per impacte
M3
Accessibilitat
Mètriques WCAG 2.1: contrast, focus, teclat, ARIA, noms, mida
M4
Text
Llegibilitat Flesch, complexitat morfosintàctica, jerarquia de capçaleres
M5
IA
Claude AI (opcional): anàlisi semàntic i notes interpretatives per mètrica
M6
Puntuació
Agregació ponderada ACI amb els 3 perfils de puntuació
M7
Exportació
Generació de JSON per slug, CSV global i manifest de reports
M8
Publicació
Jinja2 + D3.js → HTML estàtic · GitHub Actions → GitHub Pages
